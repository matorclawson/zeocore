**A data-only UI card contract: `zeo.ui-result/v1` with one read-only card (zeocore-SOW-42).** `zeocore validate zeo.ui-result/v1 < doc.json` and `zeocore schema zeo.ui-result/v1` (registered as `ui.result-card`) check the closed, strict envelope of zeocore-SOW-38 rev 8 for exactly one `card` component with no actions: closed keys at every level, the three identifier grammars, text classes S, D and L in UTF-8 bytes under pinned Unicode 16.0.0 tables, the timestamp, decimal and integer profiles, and byte limits measured on the text as received (response 262,144, component 65,536, depth 9; duplicate keys, a byte-order mark, a lone surrogate, NaN and text after the value are refused). Other kinds are refused, not coerced. The check performs no I/O and an error never echoes a value.

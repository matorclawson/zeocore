**Newsletter converter: hidden-text rules narrow only on proof (zeocore-SOW-41).** `max-height`, `max-width`, a zero size, an off-screen offset and `clip` drop text only where the condition can hold; a style that does not clip, an inline box or a table part keeps it. The rule is a whitelist: every occurrence of each property must be in a closed safe set, and `!important`, `var()`, CSS-wide keywords, `all`, comments, escapes, `<link>`, `@import`, `<style media>`, `<template>` styles, nesting and case-only class matches all mean "not proven", so the text is dropped as before. Matched classes and merged rules are bounded.

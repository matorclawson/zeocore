**Newsletter converter: a stylesheet rule that provably cannot match an element no longer stops the hidden-text proof (zeocore-SOW-41).** A CSS comment no longer marks the whole sheet as not modelled, and a rule with a type or descendant selector (`td p`, `body`, `div .note`) is checked against the element and its ancestors: only a rule that can match keeps the old behaviour of dropping the text. The grammar is closed and bounded; attribute and pseudo selectors, `>`, `+`, `~`, `*`, namespaces, escapes, at-rules and over-long selectors still mark the sheet as not modelled. Held newsletters whose only triggers were a comment or a rule that cannot match the element are now converted.

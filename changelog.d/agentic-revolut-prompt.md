**Revolut local enrollment reads the redirect URL without a blind prompt.** `python -m zeo_core.integrations.revolut.local complete` still prompts with hidden input on a terminal. Without one it reads the first line of stdin (at most 8192 bytes, the whole line within 30 seconds, UTF-8 only), and refuses with `REDIRECT_URL`, exit 2, and the next action if there is none. A URL given as an argument is refused without being echoed, and no usage error quotes the command line. The one-time code never appears as an argument, in output or in an error. The step is declared as a human checkpoint in the module, the Revolut guide and AGENTS.md. `authorize --client-id` refuses a value that looks like an address (`CLIENT_ID`, exit 2) without echoing it.

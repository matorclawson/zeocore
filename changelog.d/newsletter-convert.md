**Newsletter conversion, stage 2 of the newsletter pipeline** (ZEOCORE-SOW-33). `zeo_core.integrations.pandoc` gains `decode_raw_message` (raw RFC 822 to bodies and headers, with Gmail's authentication verdict on the sender: only the topmost `Authentication-Results` from `mx.google.com` is believed), `convert_newsletter` (a message's HTML to clean Markdown through a sandboxed pandoc: hidden text, tracking pixels, tracking parameters, unsubscribe lines and unsafe links removed and counted; tracked links flagged; one time budget for cleaning and pandoc; bounded size, elements and nesting; no markup survives into the Markdown) and `render_email_html` (Markdown to a small email-safe HTML subset through a pinned renderer: the pandoc binary and a Lua allowlist filter are copied into a private directory, hashed and run as the copies, and the result carries a renderer tuple and digest). Every failure is a typed `NewsletterRefusalError` with a fixed message that ends with the next action. The existing file-based converter is unchanged. See `docs/how-to/newsletter-convert.md`.

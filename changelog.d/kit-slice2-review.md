**kit: a plan file can no longer apply changes its review never showed.** The council found that Go's JSON decoder matches keys without regard to case, so a plan file carrying `changes` and `Changes` showed a reviewer one list and applied the other; `apply --plan` now refuses any file whose bytes are not exactly what the kit would have printed. Also: `help --json` lists the exit codes `plan` and `apply` can reach; a hook that fails half way is read back and put back (`undone`) or reported `recovery_required`, not called "failed"; a failed backup stops the apply; no error echoes a plan path, a subject or a target raw; `Canonical` and `Digest` now refuse invalid UTF-8, lone surrogate escapes and documents over 1 MiB, as `zeocore digest` does; the plan refuses non-UTF-8 values and repeated targets; the undo path is quoted and `StateDir` must be absolute; and the docs describe plan and apply.

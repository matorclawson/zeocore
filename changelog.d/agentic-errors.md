**Errors say what to do** (SOW-31 rule 7). A failing `zeocore` answer's `message` now ends with the next action, after a `;`: a command, a flag, or who has to act. Where a layer below gave no next step, the answer adds one by outcome. An internal error (exit 1) now carries a fixed message telling the caller to rerun the command with `ZEOCORE_DEBUG=1` and report it; with that variable set to `1`, stderr gets the exception's type and the file, line and function of each frame, never its text or the input, and stdout stays one JSON line. Exit codes and outcome names are unchanged.

bump: minor
**`zeocore doctor` no longer fails an agent for an extra it doesn't need.** A missing `github` extra, which only `zeocore release` uses, is now reported as optional (`ok`, `optional: true`, `needed_for: ["release"]`, with the install command) and doesn't make the result `not_ready`. `zeocore doctor --for release` names the job: then that extra is required and a missing one fails with exit 20, as before, and the result carries `"for": "release"`. `--for` takes `release` today, and any other value is refused with exit 2 without quoting it. Nothing else in doctor changes.

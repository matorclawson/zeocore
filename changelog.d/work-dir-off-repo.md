**`ZEO_WORK_DIR` keeps a checkout's environment and output off the repository.** With it set, `make` puts the virtual environment, the docs site, build output, coverage data and the pytest, mypy, ruff and bytecode caches under `$ZEO_WORK_DIR/<checkout directory name>/`, and the checkout holds only the repository. This is the org's rule from the operator, 2026-10-12: repositories on one volume, CI and local runs on another. Unset, nothing changes: everything stays inside the checkout, as for any contributor and in CI. Example: `make setup ZEO_WORK_DIR=/Volumes/ZeoWork/zeocore`, or export it in the session's environment so the pre-push hook's `make verify` uses it too.

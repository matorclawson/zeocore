**kit: a draft shared client contract (`kit/client`), at ZEOCORE-SOW-35 rev e.** The root-owned host file decides where a service is (a release build with no host file refuses; only a `zeodev` build takes an environment variable, and never with the credential). No redirects, no environment proxy, HTTP/1.1 only, trust roots from the bundle. Writes are stored first and marked unknown before any byte is sent; a new write never overtakes the queue; a torn file holds the order. The `zeo.client-result/v1` document has a closed reason set and its exit mapping. It is a draft until the council rules; nothing adopts it yet. Standard library only.

**The newsletter converter: a pinned pandoc, and a narrower hidden-text rule.** `convert_newsletter` and `convert_decoded_message` take `pandoc_path` and `expected_pandoc_sha256` (an absolute path and a digest; no `PATH` lookup; a relative path is `pandoc_missing`, another digest `renderer_mismatch`). The hidden-text filter now follows the council's ruling zc-dtl-webkit-b312-v1: `max-height:0`/`max-width:0` hides only a box that clips (`overflow:hidden` or `clip`) and is not inline, and `mso-hide:all` alone is no longer hidden, because browsers paint both. The noise data file's version is 2026-10-18, so a stored item's `converter` says which rule produced it.

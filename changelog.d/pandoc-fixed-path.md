**The newsletter converter takes a pinned pandoc, and `mso-hide:all` alone is no longer hidden.** `convert_newsletter` and `convert_decoded_message` take `pandoc_path` and `expected_pandoc_sha256` (an absolute path and a digest; no `PATH` lookup; a relative path is `pandoc_missing`, another digest `renderer_mismatch`; the binary is still copied, hashed and verified before it runs). `mso-hide:all` alone is no longer counted as hidden, because only Outlook honours it and browsers paint the text (council zc-dtl-webkit-b312-v1). Every other hiding rule is as before. The noise data file's version is 2026-10-18, so a stored item's `converter` shows which rule set ran.
